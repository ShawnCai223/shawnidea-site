I had been thinking about building my own website for a long time, but I never really knew where to start.

Recently, with the rapid development of AI and many new tools becoming more accessible, I finally had the chance to build one.

For this website, the backend runs on AWS. The server is hosted on EC2, storage is handled with S3, and an Elastic IP is used to keep the service running with a fixed address. The domain name is managed through Cloudflare, where I purchased **shawnidea.com** and linked it to the server IP.

At the beginning, I considered using WordPress, which is a well-known platform for building websites. However, I wanted more control over the design and style.

As you can see from the navigation bar, this website is mainly a place for me to share my projects and write about thoughts or moments from life.

If you happen to come across this site, read a post, or even leave a message through the Contact page, that would mean a lot to me.
